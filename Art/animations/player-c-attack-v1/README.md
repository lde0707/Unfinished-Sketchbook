# 제자리 공격 · 3타 정면 찌르기

현재 선택: `combo-window250-v9` (휘두름 타이밍은 matched-swing-v8 유지). Unity 적용 완료: 2026-10-18.

- 기존 준비·회복 포함 360 / 290 / 460ms. 1·3타6장, 2타는 준비2장·타격1장·마무리1장을 재생한다.
- 1·2타 원화 유지. 2타를 끝까지 휘두른 뒤 팔을 거두어 3타에서 정면으로 찌른다.
- 2타 마지막 프레임과 3타 첫 프레임은 동일한 전신 그림을 공유한다.
- 입력 기억150ms, 콤보 창250ms, 3타 후 공격 제한500ms. 이동은 계속 가능.
- `sources/attack3-thrust-keys.png`: 새 찌르기 원화. 예전 내려치기 원본도 보관.
- 내장 imagegen 사용. 정확한 프롬프트는 `design.json` 및 `sources/attack3-thrust-prompt.txt`.
- 원화를 분할하고 전신 크기·위치만 정렬. 관절 리그·모핑 없음.
- `preview.html`: 클릭/J 공격, 프레임1~18 확인. 이동 화면에서는 A/D 이동.
- `browser-validation.json`: 타이밍·콤보·원화 보존 검사 결과.
- Unity World12Prototype에 적용했다. 실제 대미지 판정은 별도 구현 대상이다.

검사: `node Tools/check_player_attack_combo.cjs` (저장소 루트에서 실행, 로컬 서버8092 필요).

찌르기 시작 시점은 제자리150ms / 이동180ms로 유지한다. 전진12ms → 타격48ms → 회수60ms로 압축한다. 기존 원화와 복귀 자세 시간, 3타 후500ms 제한은 유지한다.

3타 전진·타격60ms 동안 뾰족한 아이보리 궤적을 별도 레이어로 표시한다. effects/thrust-vfx.js를 공유하고 원화·타이밍은 유지한다. 내장 imagegen 프롬프트는 제자리 공격 effects/thrust-spike-prompt.txt에 보관한다.

2타는 준비 뒤 휘두름 한 장70ms → 마무리 자세140ms → 기존3타 순서로 연결한다. 중간 휘두름 원화는 재생에서 제외하며 프레임 검사에서는 확인할 수 있다. 원화와1·3타, 찌르기 이펙트는 유지한다.

2타 준비와 타격 자세 표시 시간은1타와 맞춘다. 제자리 준비80ms·타격70ms, 이동 준비160ms·타격100ms. 단일 휘두름과3타 전140ms 간격은 유지한다.
