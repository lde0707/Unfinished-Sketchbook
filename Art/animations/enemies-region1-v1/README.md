# 1지역 몬스터 애니메이션 v1

2026-10-19. 18종, 이동·공격·죽음 각 4프레임, 총 216프레임.

피격 동작은 사용자 요청으로 삭제했다. 원본 시트, 분리 프레임, Unity 시트와 상태 데이터, 미리보기에서 제거했다. Unity의 비치명적 피격은 색 변화만 표시하며 기존 애니메이션 시간을 유지한다.

## 제작과 파일

- 내장 imagegen으로 기존 몬스터 시안을 참고해 자세별 원화를 생성했다. 생성 기록은 `generation.json`, 실제 사용 프롬프트는 `prompts.json`에 있다. 최초 프롬프트의 피격 행은 이후 삭제되었으며 현재 산출물에는 포함되지 않는다.
- `sources/`: 피격 행을 제거한 생성 원화.
- `frames/`: 종마다 384×384 투명 PNG 12장.
- `atlases/`: 종마다 1536×1152, 4열×3행 시트. 위에서 이동·공격·죽음 순서.
- `manifest.json`: 프레임별 시간·피벗·크기. `placements.json`: 기존 Unity 일반 적 슬롯과 종 연결.
- `preview.html`: 모든 동작을 비교하는 미리보기. 맵 보기는 Unity 캡처 위에 합성한 브라우저 화면이다.
- `package.py`: 원화 분리·정렬 및 Unity 리소스 내보내기. 새 자세를 절차적으로 그리거나 관절 리깅하지 않는다.

## Unity 범위

`Book/Assets/Unfin/Resources/EnemyAnimations`와 `PaperEnemyAnimation`에 연결했다. 근거리에서 제한된 순찰과 공격 동작을 재생하고, 테스트 체력 3회 소진 시 죽음 후 숨긴다. 리셋하면 복원한다. 공격 피해·투사체·패링·보상 구현은 포함하지 않는다. 2지역과 보스·엘리트는 기존 상태를 유지한다.

2026-10-19 추가: `EnemyAttackMotion`으로 13종의 공격을 실제 위치 이동에 연결했다. 예고 2프레임에는 정지하고 실행 프레임에 이동한다. 구르기·들이받기·밀치기는 수평 이동, 귀뚜라미·도마뱀은 낮은 포물선, 나방은 급강하, 부엉이는 수평 활공, 갱등 주머니·거미는 하강 후 상승한다. 뿌리 매듭개는 근거리 접근 후 물기다. 지상 이동은 발판 끝과 벽을 검사하며, 공중 이동은 고체 지형을 통과하지 않는다. 공격 후 도착 지점을 순찰 기준으로 사용해 원래 위치로 순간이동하지 않는다.

`node Tools/prepare_enemy_motion_preview.cjs`로 실제 Unity 게임을 포함한 `http://127.0.0.1:8080/enemy-motion-preview.html`을 만든다. 13개 버튼으로 해당 몬스터 주변의 유효한 지상 위치로 이동한다.

검증: `EnemyAnimationValidation.Run`의 상태 전환·피격 연속성·죽음·리셋 검사 및 `Tools/check_enemy_animation_preview.cjs`의 18종 이미지와 미리보기 조작 검사.
