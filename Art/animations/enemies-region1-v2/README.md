# 몬스터 프레임 보강 v2

1지역 18종 중 구겨진 종이공(COMMON01), 종이 나방(COMMON02), 종이 귀뚜라미(A02), 옹이 도마뱀(C02)의 이동·공격을 각각 4→8프레임으로 보강했다. 몸 말기/풀기, 날개 접기/펴기, 도약 준비/착지에서 자세 차이가 커 우선 선정했다.

새 원화 32장을 추가해 전체 248프레임이다. 기존 v1의 216프레임을 픽셀 그대로 포함한다. 나머지 14종과 죽음 동작은 변경하지 않았고 피격 동작은 없다. 기존 프레임을 복제하거나 관절을 보간한 것이 아니라 내장 imagegen으로 중간 자세를 그렸다. 사용한 프롬프트·생성 원본 경로는 `generation.json`과 `corrections.json`에 기록한다.

- `sources/`: 선택한 중간 자세 원화, 종마다 4열×2행.
- `frames/`: Unity용 384×384 투명 프레임.
- `atlases/`: 보강 4종은 4열×5행(1536×1920), 나머지는 4열×3행.
- `manifest.json`: 종별 프레임 수·시작 인덱스·지속 시간.
- `preview.html`: 18종의 이동·공격·죽음 비교와 프레임 단위 재생.

이동 한 주기는 기존과 같은 0.48초다. 공격은 원래 예고·실행·회복 구간을 유지하면서 각 구간의 자세를 세분화했다. `motionDurations`는 기존 네 단계 타이밍을 보존하므로 실제 돌진 거리·도약 궤적과 공격 총시간이 바뀌지 않는다. Unity는 고정 12프레임이 아니라 각 클립 길이와 시트 행 수를 읽는다.

검증: 원본 216프레임의 픽셀 보존, 32개 새 프레임의 고유성, 공격 총시간 보존, Unity 이동·공격·죽음·피격 연속성·리셋, 18종 미리보기 로딩. 생성은 기본 내장 imagegen 모드를 사용했다.
