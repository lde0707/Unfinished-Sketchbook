# 1지역 컬러 타일맵 — Unity 적용

색조를 수정한 네 구역의 A/B/C 원화 묶음을 실제 1지역 전체에 적용한다. 이 폴더의 `straight` / `steps`는 재질 비교 시안이며, Unity용 데이터는 실제 지도에서 별도로 생성한다.

- A · 구겨진 종이굴: 따뜻한 회갈색. 방 1~6, 25.
- B · 흑연 광산: 차가운 청회색. 방 7~12, 27, 29, 30.
- C · 스케치 나무 속: 목재 갈색. 방 13~17, 26.
- D · 엉킨 뿌리 심부: 이끼빛 회녹색. 방 18~24, 28.

## 파일 구분

- `sources/`: 내장 이미지 생성으로 수정한 재질 원화. 프롬프트는 `prompts.json`, 최종 색 수정은 `color-revision.json`.
- 구역별 `module-A/B/C.png`: 512×384px, 가로 4칸·깊이 3칸의 연속 재질.
- 구역별 `tiles/`, `atlas.png`, `*-tilemap.json`: 두 비교 시안용 128px 타일.
- `Book/Assets/Unfin/Art/Region1V8/`: 실제 월드용 아틀라스, 셀 배치 `manifest.json`, Unity 카탈로그 `Region1Terrain.asset`.
- `Book/Assets/Scenes/World12Prototype.unity`: 플레이용 씬.
- `Book/Validation/region1-v8-*`: 전체 셀 검사와 실제 Unity 구역별 렌더.

## 연결 규칙

128×128px / PPU 128을 유지한다. 재질은 한 칸마다 다시 시작하지 않고 월드 좌표를 따라 네 칸 길이로 흐른다. A/B/C 묶음은 순서를 바꾸어 배치하며, 노출면에서 384px 깊이에 걸쳐 거의 검정으로 어두워진다. 바닥·벽·천장은 같은 원화를 방향에 맞춰 샘플링한다. 바깥 모서리의 기본 반경은 28px, 안쪽 연결 조각은 24px이다.

**윤곽 보정:** 색 텍스처를 정렬하기 전에 원화 상단의 높이 신호를 `surface-profile.json`에 보존한다. 이를 약 2~12px 범위의 불규칙한 외곽선으로 적용하고, 색 텍스처의 깊이도 같은 윤곽을 따른다. 작은 가시 모양은 완화하되 서로 다른 크기의 굴곡은 유지한다. 이전의 최대 2.4px 반복 사인파와 묶음 끝에서 높이를 0으로 만드는 처리는 제거했다. A/B/C 접합점은 동일한 높이 정보를 공유하며, 모서리에도 요철을 이어 붙인다. 충돌은 기존 사각 격자를 사용하므로 시각적 요철과 최대 12px 차이가 있을 수 있다.

검증기는 실제 출력 PNG의 알파 경계를 측정한다. 네 구역 각각의 바닥·벽·천장에서 6px 이상의 높이 변화가 남는지, 직선 노출면이 13px 안쪽 범위에 있는지 확인한다. 변환 후 다시 평탄해지는 회귀를 수치로 잡는다.

방의 A/B/C/D 구역 표기와 방 경계까지의 거리를 사용해 재질을 고른다. 구역 경계와 통로에서는 약 4칸에 걸쳐 재질과 색을 섞는다. 아틀라스의 각 타일에는 2px 가장자리 확장을 넣어 확대·축소 시 다른 타일 색이 새지 않도록 한다.

실제 맵의 일반 지형은 전부 새 타일을 사용한다. 특수 발판·물·게이트의 식별 색과 2지역은 기존 규칙을 유지한다. 안쪽 연결 조각은 충돌 없는 별도 Tilemap이며, 게이트가 열리거나 임시 발판이 사라질 때도 해당 위치의 새 재질을 유지한다.

## 재생성

1. 원화가 바뀌면 `node Art/samples/region1-tiles-v8/build.cjs`로 묶음과 시안을 갱신한다.
2. `node Tools/export_region1_terrain.cjs`로 실제 맵용 128px 아틀라스를 생성한다.
3. `node Tools/verify_region1_terrain.cjs`로 전체 셀 누락, 타일 재사용, 아틀라스 여백을 검사한다.
4. Unity 메뉴 **Unfin → Apply Region 1 Colored Tilemaps**로 임포트·씬 재생성·검증·구역별 렌더를 실행한다.

이 에셋은 현재 맵의 연결 상태를 베이크한 타일맵이다. 맵 구조를 변경하면 2~4단계를 다시 실행한다. 원본 격자 해시가 맞지 않으면 Unity 임포터가 중단한다. 생성 전용 씬이므로 수작업 씬 수정은 별도 씬으로 보관한다. 임의 지형 파괴를 런타임에서 지원하는 시스템은 아니다.
