# 둥근 지형 질감 · 현재 World 1·2 원화

2026-10-16 사용자 피드백 반영. 현재 Unity에서 사용하는 그래파이트·크레파스 바닥/벽 4장을 내장 `image_gen`으로 수정했다. 이전 v4는 작업 이력으로 보존하고, Unity 생성기는 이 폴더의 새 원화를 참조한다.

- 뾰족한 파편, 칼날 같은 조각, 삼각형 면, 거미줄 같은 깊은 균열을 줄인다.
- 넓고 둥근 덩어리, 완만한 층, 얕은 곡선 이음과 절제된 무광 재질로 표현한다. 흐리게 만드는 대신 큰 형태 자체를 바꾼다.
- 그래파이트는 어두운 회색의 흐르는 층, 크레파스는 따뜻한 갈색의 둥글게 닳은 밀랍 층으로 구분한다. 진지한 메트로배니아 분위기를 유지한다.
- 256×256px 원화와 128×128px Unity 파생 타일. 바닥 윗면은 원화에서 4px, Unity에서 2px다.
- 바닥 아래와 벽 안쪽은 거의 검정이다. `validation.json`의 깊은 내부 평균 밝기는 0~255 기준 16 이하를 확인한다.
- 기존 8방향 연결 규칙으로 두 지역 각 47종, 총 94종을 다시 생성한다. 맵·충돌·카메라 규격은 유지한다.

`sources/`에 생성된 고해상도 원본, `prompts.json`에 실제 생성 프롬프트와 입력 버전 정보를 보관한다. 루트 PNG 4장은 실제 Unity 생성 입력이다. `active-region-pairs.png`는 위쪽 바닥/아래쪽 벽, 왼쪽 그래파이트/오른쪽 크레파스 순서다.

재출력: `node Art/samples/regional-pairs-v5-soft/export.cjs`. `sharp`가 필요하며, 일반 Node 모듈 또는 `UNFIN_SHARP_PATH`로 지정할 수 있다. Unity 씬 재생성은 `Unfin.Editor.WorldPrototypeBuilder.BuildAndRender`를 그래픽 장치와 함께 실행한다.
