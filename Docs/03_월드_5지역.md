# 03. 월드 · 5개 지역

## 🗺️ 월드 구조 ✅

- 거대한 스케치북 한 권 = 맵 하나, 그 안에 **5개 지역**
- **1지역 연필 숲이 가운데 허브**, 나머지 지역이 사방으로 뻗는 구조 (할로우 나이트식 방사형)
- **5지역 잉크 심연**은 허브 바로 아래에 있지만 **보스 4마리를 잡아야** 봉인이 풀림
- 지역 사이는 **수직 샤프트 1~2개**로 단순하게 연결 (슈퍼 메트로이드식)

```mermaid
flowchart LR
  A["1 연필 숲<br/>획득: 지우개 대시"] -->|"낙서 벽 파괴"| B["2 크레파스 언덕<br/>획득: 크레파스 벽타기"]
  B -->|"서쪽 높은 절벽"| C["3 수채화 호수<br/>획득: 물감 헤엄"]
  C -->|"수중 통로 · 폭포 상승"| D["4 색종이 도시<br/>획득: 종이접기 활공"]
  D -->|"보스 4마리 처치"| E["5 잉크 심연<br/>최종 보스 번짐"]
```

## 📋 지역 한눈에 보기

| # | 지역 | 테마 | 보스 | 획득 능력 | 열리는 길 |
|---|---|---|---|---|---|
| 1 | 🌲 연필 숲 | 흑백 연필 스케치 숲. 허브 | 엉킨 낙서 덩어리 | 지우개 대시 (중간: 연필 깎기) | 낙서 벽 파괴, 동쪽 출구 |
| 2 | 🖍️ 크레파스 언덕 | 두껍게 덧칠된 노을색 능선과 협곡 | 부러진 크레파스 기사 | 크레파스 벽타기 | 서쪽 높은 절벽 |
| 3 | 💧 수채화 호수 | 물 높이가 오르내리는 번진 호수 | 번진 물감 고래 | 물감 헤엄 | 수중 통로, 폭포 |
| 4 | 📄 색종이 도시 | 접힌 종이 도시, 상층은 제도판 탑 | 접힌 종이 왕 | 종이접기 활공 | 넓은 낭떠러지, 심연 봉인 조건 |
| 5 | 🖋️ 잉크 심연 | 이전 지역 조각이 잉크에 잠긴 최종 지역 | 번짐 | 없음 (모든 능력 총동원) | 엔딩 |

> 초기 7챕터 안을 5지역으로 압축했어. 제도판 탑은 색종이 도시 상층으로, 유화 화산은 잉크 심연 입구로 합침.

## 🧭 몬스터 구성 원칙 ✅

| 구분 | 지역당 | 비고 |
|---|---|---|
| 일반 몬스터 | **6~12종** | 지역 고유 신규 + 이전 지역 재등장 |
| 엘리트 | 1~2종 | 중간 능력 또는 체력 조각 보상 |
| 보스 | 1 | 지역 메인 능력 보상 |
| 강화판(색 바꾼 변형) | 1~2종, **소수만 등장** | 많이 쓰면 성의 없어 보임 |

## 🌲 1지역 · 연필 숲 (상세는 [04 문서](04_1지역_연필숲_맵.md))

| 항목 | 내용 |
|---|---|
| 구역 | 백지 들판 · 흑연 광산 · 스케치 나무 · 엉킨 숲 심부 (4구역) |
| 능력 | 연필 깎기 (엘리트) → 지우개 대시 (보스) |
| 기믹 | 흑연 덩굴, 낙서 벽, 무너지는 발판, 잉크 웅덩이, 일방통행 문 |
| 위층 구간 | 바람 굴뚝, 광산 승강로, 다리 아래 굴, 쉼터 아래 굴, 나무 속 탑(46타일) |
| 90° 구간 | 덩굴 길(가로) 끝에서 덩굴 수직굴(세로 40타일)로 꺾임 |

## 🖍️ 2지역 · 크레파스 언덕 (설계 단계)

| 항목 | 내용 |
|---|---|
| 등장 요소 | 녹는 크레파스 발판(밟고 1.5초 뒤 녹음), 밀랍 절벽(벽타기로만), 3색 스위치(빨강→노랑→파랑), 색 막대 다리(공격하면 내려옴) |
| 상호작용 | 불씨 화로 근처 발판은 더 빨리 녹음 · 벽타기 ↔ 밀랍 절벽 · 3색 스위치 ↔ 보스방 문 |
| 위층 구간 | 크레파스 탑 외벽 벽타기 구간 |
| 90° 구간 | 언덕 능선(가로)에서 협곡(세로)으로 꺾여 내려감 |

| 몬스터 | 유형 | 행동 |
|---|---|---|
| 크레용 병정 | 근거리 | 창을 앞으로 찌르는 2연속 공격 |
| 밀랍 투척꾼 | 원거리 | 포물선 밀랍 덩이, 바닥에 잠깐 남음 |
| 색가루 박쥐 | 비행 | 천장에 매달렸다가 급강하 |
| 깎인 크레파스 거북 | 엘리트 | 정면 공격을 막음, 뒤를 노려야 함 |
| 부러진 크레파스 기사 | 보스 | 부러진 창 돌진, 벽에 꽂혀 발판을 만듦 |

> 패링 관련 내용은 2장 개발 때 별도 문서로 정리 예정.

## 💧 3지역 · 수채화 호수 (설계 단계)

| 항목 | 내용 |
|---|---|
| 등장 요소 | 수위 레버(물 높이 3단계), 물감 방울(타면 위로 떠오름), 젖은 종이 바닥(오래 서 있으면 찢어짐) |
| 상호작용 | 수위 ↔ 문 높이 (물을 빼야 열리는 문 / 채워야 닿는 문) · 물감 헤엄 ↔ 수중 구간 |
| 위층 구간 | 폭포 옆 물감 방울 상승 구간 |
| 90° 구간 | 호숫가(가로)에서 잠수 갱도(세로)로 꺾임 |

| 몬스터 | 유형 | 행동 |
|---|---|---|
| 물감 개구리 | 근거리 | 도약해서 덮침 |
| 붓털 물총새 | 원거리 | 직선 물줄기 3연사 |
| 번짐 해파리 | 비행 | 물 위를 떠다니며 접촉 피해 |
| 스펀지 문지기 | 엘리트 | 물을 빨아 커졌다가 짜내는 광역 공격 |
| 번진 물감 고래 | 보스 | 수위를 바꾸며 싸우는 2단 보스 |

## 📄 4지역 · 색종이 도시 (설계 단계)

| 항목 | 내용 |
|---|---|
| 등장 요소 | 접기 스위치(벽이 접혀 길이 바뀜), 바람 통로(활공 중 위로), 가위 함정(일정 박자로 닫힘), 컴퍼스 리프트(원을 그리며 도는 발판) |
| 상호작용 | 접기 스위치를 치면 통로가 **가로 → 세로로 90° 바뀜** · 활공 ↔ 바람 통로 · 가위 함정 ↔ 박자 |
| 위층 구간 | 제도판 탑 컴퍼스 리프트 |
| 90° 구간 | 접기 스위치 방 |

| 몬스터 | 유형 | 행동 |
|---|---|---|
| 접지 병사 | 근거리 | 종이 방패로 막다가 반격 |
| 색종이 수리검병 | 원거리 | 3방향 수리검 |
| 종이학 경비 | 비행 | 원을 그리다 급강하 |
| 가위 집행관 | 엘리트 | 2단 베기, 사이에 빈틈 |
| 접힌 종이 왕 | 보스 | 방을 접었다 펴며 지형을 바꿈 |

## 🖋️ 5지역 · 잉크 심연 (설계 단계)

| 항목 | 내용 |
|---|---|
| 등장 요소 | 잉크 조류(일정 시간마다 바닥부터 차오름), 이전 지역 조각(1~4지역 방이 잉크에 덮여 재등장), 7색 덧칠 제단 |
| 상호작용 | 덧칠 ↔ 잉크 벽 (맞는 색을 칠해야 열림) · 대시 → 벽타기 → 활공 연속 퍼즐 · 최종전 3페이즈 덧칠 |
| 위층 구간 | 거꾸로 흐르는 잉크 폭포 |
| 90° 구간 | 심연 나선 계단 (가로 → 세로로 감기며 하강) |

| 몬스터 | 유형 | 행동 |
|---|---|---|
| 잉크 벌레 | 근거리 | 흑연 벌레의 검은 변형, 더 빠름 |
| 잉크 포탑 | 원거리 | 탄이 바닥에 웅덩이를 남김 |
| 잉크 나비 | 비행 | 죽으면 작은 나비 2마리로 갈라짐 |
| 그림자 주인공 | 엘리트 | 플레이어 동작을 따라 하는 거울 적 |
| 번짐 | 보스 | 3페이즈: 잉크 괴물 → 주인공 복제 → 덧칠로 정화 |
