# 09. 미확정 · 다음 과제

처치 보상용 **먹빛 가루 + 두 거점의 갈피 교환소**는 구현 완료. 교환소는 시작의 백지길과 삼색 광장에 한 곳씩 두며, 일반 저장 지점과 분리한다. 흑연 조각과 분리하며 상세 수치·구매 항목은 [10 문서](10_능력_성장.md)의 처치 보상 절을 따른다.

## ❓ 결정이 필요한 것

| 항목 | 선택지 | 추천 |
|---|---|---|
| 흑연 조각 활용 | ① 6개 모아 **연필심 강화** (공격 범위·공격력·대시 쿨다운 중 선택) ② **세상 다시 그리기** (점선 다리·사다리를 흑연으로 그려 지름길·숨은 방 개방) ③ ~~미완성 캐릭터 구출~~ (흑연과 분리 확정, [14 문서](14_숨은_그림친구.md)) ④ 갈피 상점 화폐 | **② + ①** (지역 안에선 ②, 남은 흑연은 ①). ③은 진 엔딩용으로 따로 |
| 흑연 ② 예시 | 9 무너진 갱도 위 점선 다리 (흑연 2개), 5 갈림길 굴 → 15 가지 속 통로 점선 사다리 (흑연 3개) | |
| 색 회복 패시브 | 보스마다 색이 돌아오며 패시브 효과 (흔적 읽기·무적 연장·회복·공격력) → 5장 덧칠과 연결 | [10 문서](10_능력_성장.md) 참고 |
| 3·4지역 중간 능력 | 물감 방울 타기 / 접기 스위치 (능력 vs 기믹) | |
| ~~진 엔딩 수집 대상~~ | ✅ 확정: 찾아가서 그 지역 도구로 빠진 부분 채우기 (E 한 번) | [14 문서](14_숨은_그림친구.md) |
| ~~벽 점프 vs 크레파스 벽타기~~ ✅ 1장 벽 점프 전용 구간 2곳으로 대비 확정 | 벽 점프는 처음부터 가능 → 2장 벽타기와 겹쳐 보임 | 벽타기 = 매끈한 밀랍 벽까지 오르는 상위 능력 |
| 엔진 | Unity 2D (URP) | 권장안 그대로 |
| ~~방 이름 토스트~~ ✅ 확정: 방 이름·지도 이름표 없음, 구역·장이 바뀔 때만 이름 표시 | 획득 알림을 실제 게임에서 유지할지는 아직 미정 | [07 문서](07_시스템_연출.md) HUD |
| 적 공격 예비 동작 표시 | 예비 동작(0.5초)은 있지만, 패링과 별개로 기본 예고 연출을 어떻게 보여줄지 | 2장 패링 문서와 함께 정리 |

| 기능 | 내용 |
