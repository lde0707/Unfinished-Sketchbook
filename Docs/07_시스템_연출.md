## 🚶 지역 전환: 걸어서 이어짐 ✅

> 🔒 **보스를 잡지 않으면 다음 지역으로 못 감.** 1장 → 2장은 보스 보상 지우개 대시로 낙서 벽을 지워야만, 2장 → 3장은 보스 보상 벽타기로 밀랍 탑을 올라야만 열림. 지도 만들 때 자동 검사 ([08 문서](08_프로토타입_QA.md)).

> 지역 사이에 **책 넘김·로딩 화면이 없어.** 통로를 걸어가면 그대로 다음 지역이야.

| 항목 | 내용 |
|---|---|
| 색 전환 | 경계 앞뒤 약 28칸 동안 종이 색·선 색이 다음 지역 색으로 서서히 섞임 |
| 장 제목 | 다음 지역에 처음 들어가면 화면 가운데 장 제목이 3초 동안 떠오르고 사라짐 (예: `2장 · 크레파스 언덕`) |
| 장 완성 | 보스 처치 순간 독백 + 표지 글자 회복 (위치 이동 없음) |
| Unity | 지역마다 씬을 나누되 경계 근처에서 **다음 씬을 미리 Additive 로딩** → 끊김 없이 이어지게 |

### 📖 (보관) 페이지 넘김 연출
> 지역 이동에는 더 이상 쓰지 않음. 프로토타입에선 3장이 없어서 2장 끝 데모 종료 화면에만 남아 있어. 나중에 엔딩·장 완성 연출로 재활용할 수 있게 사양은 남겨 둠.

| 항목 | 값 |
|---|---|
| 넘어가는 장 수 | **6장** (현재 게임 화면 1장 + 빈 페이지 5장) |
| 장 사이 간격 | 0.09초 |
| 한 장 넘김 시간 | 0.62초 (가속 → 감속) |
| 전체 시간 | 약 1.1초 |
| 책등 | 화면 **왼쪽 가장자리** |
| 회전 | 0° → **180°** (왼쪽으로 완전히 넘어감) |
| 종이 휨 | 오른쪽 끝이 먼저 들리며 둥글게 휨 (휨 강도 0.9 × sin, 뒤 장들은 0.75배) |
| 원근 | 들린 부분이 화면 쪽으로 다가오며 커짐 |
| 그림자 | 넘어가는 종이 아래 다음 장에 그림자, 들린 면은 점점 어두워짐 |
| 빈 페이지 | 연한 낙서 + 쪽수 표시 (— 37 — 등) |
| 마지막 | 다음 지역 화면(장 제목 페이지)이 드러남 |

### Unity 구현 메모
1. 현재 화면을 **Render Texture**로 캡처 → 첫 장 텍스처
2. 페이지 1장 = **가로로 잘게 나눈 메시** (프로토타입은 56조각). 조각마다 회전 각도를 다르게 줘서 휘는 느낌
3. 빈 페이지 5장은 **같은 종이 텍스처 재활용**
4. 넘기는 동안 `SceneManager.LoadSceneAsync`로 다음 지역 로딩 → 로딩 화면 역할
5. 효과음: 종이 넘기는 소리를 **장마다 짧게 겹치기**

### 2026-10-25 · Stilldrawn 인게임 UI

실제 HUD는 `WorldGameplayHud`가 담당한다. 왼쪽 위에는 현재·최대 체력을 종이 조각과 숫자로 함께 표시하고 반 칸 체력도 반영한다. 흑연은 실제 보유 수량을 표시한다. 회복 횟수와 종이 방패는 획득한 뒤에만 표시하며, 소모 여부를 반영한다. 아래 왼쪽에는 공격·점프와 해금한 대시·패링의 조작 키를 표시한다. 긴 상시 조작 설명은 제거한다.

오른쪽 위에는 탐험한 지형만 기록하는 미니맵, 그림 친구 수, 지도·메뉴 버튼을 둔다. M 또는 미니맵 버튼으로 전체 지도를 열고, 지역 탭·전체 연결·개인 목적지 표시와 지우기를 지원한다. 지도는 순간이동 기능이 아니며 M·Esc·닫기로 게임에 돌아간다. 일시정지는 기존 Stilldrawn 메뉴와 연결한다. 종이색 글씨, 흑연색 반투명 판, 얇은 황동색 선으로 타이틀과 질감을 맞춘다. 1920×1080 기준 비율을 유지해 다른 화면 비율에서도 글씨와 아이콘을 찌그러뜨리지 않는다. 방 이름·번호를 인게임에 띄우지 않는 기존 원칙은 유지한다.

## 2026-10-21 · 탐험 기록과 재방문 (Unity)

미니맵은 이동한 주변을 기록하며, 미탐험 구역의 세부 지형은 숨긴다. 직접 본 막힌 길만 지도에 남긴다. 미해금 길은 주황, 능력을 얻어 다시 갈 수 있는 길은 청록, 통과한 봉인은 일반 길로 표시한다. 사망·부활해도 능력·수집품·탐험 기록·열어 둔 길은 유지한다.

M 전체 지도에서 1지역·2지역·전체 연결을 볼 수 있고, 클릭은 개인 표식으로 사용한다. 지도 클릭으로 비행하거나 순간이동하지 않는다. 기존 F 비행은 검토용으로 유지하며 E 게이트 강제 해제는 비행 중에만 가능하다.


## 2026-10-24 · Stilldrawn 타이틀

현재 타이틀 표기는 **Stilldrawn**이다. 공개 PC 게임 30종의 타이틀·메뉴 캡처와 UI 자료를 정성 비교한 출처·관찰·채택·제외 기록은 `Art/title/stilldrawn-v1/research.json`에 둔다. 직접 30개 게임을 설치해 측정한 결과가 아니다.

- 핵심 방향: 왼쪽 여백에 상아색 로고와 짧은 세로 메뉴, 오른쪽에 펼쳐진 미완성 스케치북. 흑연 숲·찢긴 종이 지형·펼쳐진 책으로 장면을 구성한다. 타이틀 위에 별도로 얹었던 플레이어와 접지 그림자는 제거한다. 큰 광원·광고·추가 모드 목록 없이 종이 입자만 느리게 움직인다.
- 이어하기 / 새 이야기 / 설정. 제작진 메뉴는 제거하고 타이틀 하단에 `기획 · 개발 · 제작 UNDO`를 표시한다. 저장이 없거나 현재 맵과 호환되지 않으면 이어하기가 비활성화된다. 새 이야기는 시작 확인 패널을 열며 기존 기록이 있으면 덮어쓰기를 안내한다. 웹에서 작동하지 않는 종료 버튼은 숨기고 브라우저 전체화면 버튼을 제공한다.
- 설정: 전체·효과음·배경음·화면 밝기와 타이틀 움직임 줄이기. 실제 게임 음원과 카메라에 반영하며 다음 실행에도 유지한다. 키보드·마우스·게임패드로 메뉴를 탐색한다. 게임패드 게임 조작 전체를 추가한 것은 아니다.
- 저장: 마지막 안전한 책갈피, 능력, 아이템·친구 획득, 강화, 발견 지도와 능력 게이트 기록, 열린 지형, 처치한 주요 적을 로컬 PlayerPrefs에 보관한다. 체크포인트 변경·30초 간격·일시정지에서 타이틀 복귀 시 저장한다. 사라지는 발판·보스의 임시 가열 지형은 영구 저장하지 않는다. 일반 적은 재입장 때 되살아난다.
- Esc로 일시정지하고 설정·조작 안내·저장 후 타이틀 복귀를 제공한다. 메뉴 중 월드·전투·행동 입력을 정지한다. 재개 입력은 게임 공격이나 점프로 전달하지 않는다.
- 웹 저장은 현재 사이트/브라우저의 로컬 기록이다. 클라우드 저장·여러 슬롯·다른 기기 동기화는 제공하지 않는다. 기존 검토 링크의 `spawn=x,y`는 타이틀을 건너뛰고 저장을 덮어쓰지 않는 검토 모드다.
