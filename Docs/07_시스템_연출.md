## 🔑 능력 게이트 (1지역) ✅

| 능력 | 얻는 곳 | 얻는 방법 | 여는 것 |
|---|---|---|---|
| 연필 깎기 (중간 능력) | 11 감독의 채굴장 | 엘리트 광산 감독 지우개 처치 → 구슬 | 흑연 덩굴 (공격으로 자름) |
| 지우개 대시 (메인 능력) | 22 보스방 | 보스 엉킨 낙서 덩어리 처치 → 구슬 | 낙서 벽 (대시로 지움) |

- **중간 능력은 엘리트, 메인 능력은 보스**가 주는 구조 (2장 이후에도 같은 틀 유지 예정)
- 중간 능력 덕분에 지역 안에서도 **되돌아오기**가 생김 (갈림길 굴 덩굴 → 스케치 나무 속)
- 새 능력은 얻자마자 **바로 써보는 자리**를 둠 (대시 → 바로 옆 24번 비밀 방)
- 막힌 덩굴을 능력 없이 치면 2.5초 간격으로 안내 토스트 (프로토타입 기준)

## 🚶 지역 전환: 걸어서 이어짐 ✅

> 🔒 **보스를 잡지 않으면 다음 지역으로 못 감.** 1장 → 2장은 보스 보상 지우개 대시로 낙서 벽을 지워야만, 2장 → 3장은 보스 보상 벽타기로 밀랍 탑을 올라야만 열림. 지도 만들 때 자동 검사 ([08 문서](08_프로토타입_QA.md)).

> 지역 사이에 **책 넘김·로딩 화면이 없어.** 통로를 걸어가면 그대로 다음 지역이야.

| 항목 | 내용 |
|---|---|
| 색 전환 | 경계 앞뒤 약 28칸 동안 종이 색·선 색이 다음 지역 색으로 서서히 섞임 |
| 장 제목 | 다음 지역에 처음 들어가면 화면 가운데 장 제목이 3초 동안 떠오르고 사라짐 (예: `2장 · 크레파스 언덕`) |
| 장 완성 | 보스 처치 순간 독백 + 표지 글자 회복 (위치 이동 없음) |
| Unity | 지역마다 씬을 나누되 경계 근처에서 **다음 씬을 미리 Additive 로딩** → 끊김 없이 이어지게 |

### 📖 (보관) 페이지 넘김 연출
> 지역 이동에는 더 이상 쓰지 않음. 프로토타입에선 3장이 없어서 2장 끝 데모 종료 화면에만 남아 있어. 나중에 엔딩·장 완성 연출로 재활용할 수 있게 사양은 남겨 둠.

| 항목 | 값 |
|---|---|
| 넘어가는 장 수 | **6장** (현재 게임 화면 1장 + 빈 페이지 5장) |
| 장 사이 간격 | 0.09초 |
| 한 장 넘김 시간 | 0.62초 (가속 → 감속) |
| 전체 시간 | 약 1.1초 |
| 책등 | 화면 **왼쪽 가장자리** |
| 회전 | 0° → **180°** (왼쪽으로 완전히 넘어감) |
| 종이 휨 | 오른쪽 끝이 먼저 들리며 둥글게 휨 (휨 강도 0.9 × sin, 뒤 장들은 0.75배) |
| 원근 | 들린 부분이 화면 쪽으로 다가오며 커짐 |
| 그림자 | 넘어가는 종이 아래 다음 장에 그림자, 들린 면은 점점 어두워짐 |
| 빈 페이지 | 연한 낙서 + 쪽수 표시 (— 37 — 등) |
| 마지막 | 다음 지역 화면(장 제목 페이지)이 드러남 |

### Unity 구현 메모
1. 현재 화면을 **Render Texture**로 캡처 → 첫 장 텍스처
2. 페이지 1장 = **가로로 잘게 나눈 메시** (프로토타입은 56조각). 조각마다 회전 각도를 다르게 줘서 휘는 느낌
3. 빈 페이지 5장은 **같은 종이 텍스처 재활용**
4. 넘기는 동안 `SceneManager.LoadSceneAsync`로 다음 지역 로딩 → 로딩 화면 역할
5. 효과음: 종이 넘기는 소리를 **장마다 짧게 겹치기**

| 💡 소리 피드백 | 실패 이유를 소리로 구분하는 방식 제안 (예: 등 뒤 피격음을 살짝 다르게) |

### 프로토타입 HUD (그레이박스용)
- 왼쪽 위: 체력 하트, 보유 능력(연필 깎기 / 지우개 대시), 흑연 조각 수
- 오른쪽 위: 플레이 타이머
- 아래 가운데: 보스 체력 바
- 위 가운데: **구역이 바뀔 때만 구역 이름** (예: "엉킨 뿌리 심부"), 장이 바뀔 때는 화면 가운데 큰 장 타이틀 (예: "2장 · 크레파스 언덕")
- ❌ 방 이름·방 번호, 수직굴·통로 이름표(`⇣ 일방통행 · 일방통행 뿌리굴`, `↑ 위층 · …`), 지도 위 화살표 안내(`→ 크레파스 언덕`)는 **인게임에 글자로 띄우지 않음** (2026-10-15 확정). 길·장치는 지형 모양과 연출로 알려 줌. 방 목록·기호는 페이지 옆 미니맵 패널(개발 확인용)에만

## 🔑 열쇠 몬스터 🧪

- 패링으로 튕긴 탄으로 장치(과녁 문, 색 막대 다리)를 여는 곳의 탄 쏘는 몬스터는 **장치가 열리기 전까지 죽지 않음**
- 공격하면 피해 대신 금빛 링이 뜨고, 몬스터 몸에 금빛 테두리 + 장치까지 금빛 점선이 이어져서 "이 몬스터 탄으로 저걸 맞혀야 한다"는 걸 텍스트 없이 알려줌
- 장치가 열리면 일반 몬스터로 돌아가서 잡을 수 있음

## 🔖 책갈피 리본 🧪

- 리본 양 끝이 맵 곳곳에 꽂혀 있고, **정해진 짝으로만** 넘어감 (선택 메뉴 없음)
- 보통 리본: 양 끝을 다 만져야 열림 · 찢긴 페이지 리본: 한쪽만 찾아도 바로, 도착지는 봉인 구역 · 매듭 리본: 아직 안 간 장과 연결
- 초반에 못 간 곳을 후반 능력 + 리본으로 다시 찾아가게 해서 1~5장을 끝까지 넘나들게 함
- 연출은 지우개로 지워졌다 연필로 다시 그려지는 방식 (지역 이동의 책 넘김과 구분)
