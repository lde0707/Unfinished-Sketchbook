# 07. 시스템 · 연출

## 🔑 능력 게이트 (1지역) ✅

| 능력 | 얻는 곳 | 얻는 방법 | 여는 것 |
|---|---|---|---|
| 연필 깎기 (중간 능력) | 11 감독의 채굴장 | 엘리트 광산 감독 지우개 처치 → 구슬 | 흑연 덩굴 (공격으로 자름) |
| 지우개 대시 (메인 능력) | 22 보스방 | 보스 엉킨 낙서 덩어리 처치 → 구슬 | 낙서 벽 (대시로 지움) |

- **중간 능력은 엘리트, 메인 능력은 보스**가 주는 구조 (2장 이후에도 같은 틀 유지 예정)
- 중간 능력 덕분에 지역 안에서도 **되돌아오기**가 생김 (갈림길 숲 덩굴 → 스케치 나무)
- 새 능력은 얻자마자 **바로 써보는 자리**를 둠 (대시 → 바로 옆 24번 비밀 방)
- 막힌 덩굴을 능력 없이 치면 2.5초 간격으로 안내 토스트 (프로토타입 기준)

## 📖 지역 전환: 페이지 넘김 연출 ✅

> 지역 출구에 닿으면 **책장이 샤라락 넘어가며 다음 지역이 자연스럽게 나타남** (줌아웃 없음)

| 항목 | 값 |
|---|---|
| 넘어가는 장 수 | **6장** (현재 게임 화면 1장 + 빈 페이지 5장) |
| 장 사이 간격 | 0.09초 |
| 한 장 넘김 시간 | 0.62초 (가속 → 감속) |
| 전체 시간 | 약 1.1초 |
| 책등 | 화면 **왼쪽 가장자리** |
| 회전 | 0° → **180°** (왼쪽으로 완전히 넘어감) |
| 종이 휨 | 오른쪽 끝이 먼저 들리며 둥글게 휨 (휨 강도 0.9 × sin, 뒤 장들은 0.75배) |
| 원근 | 들린 부분이 화면 쪽으로 다가오며 커짐 |
| 그림자 | 넘어가는 종이 아래 다음 장에 그림자, 들린 면은 점점 어두워짐 |
| 빈 페이지 | 연한 낙서 + 쪽수 표시 (— 37 — 등) |
| 마지막 | 다음 지역 화면(장 제목 페이지)이 드러남 |

### Unity 구현 메모
1. 현재 화면을 **Render Texture**로 캡처 → 첫 장 텍스처
2. 페이지 1장 = **가로로 잘게 나눈 메시** (프로토타입은 56조각). 조각마다 회전 각도를 다르게 줘서 휘는 느낌
3. 빈 페이지 5장은 **같은 종이 텍스처 재활용**
4. 넘기는 동안 `SceneManager.LoadSceneAsync`로 다음 지역 로딩 → 로딩 화면 역할
5. 효과음: 종이 넘기는 소리를 **장마다 짧게 겹치기**
