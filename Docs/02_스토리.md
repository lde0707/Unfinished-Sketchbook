# 02. 스토리

> 상태: ✅ 5지역 기준 스토리 (주인공 이름 없음, 주인공 시점)

## 🌍 세계관 한 줄
어떤 작가가 그리다 버려둔 스케치북 속 세상. 작가가 펜을 놓은 뒤 페이지 사이로 검은 잉크 얼룩 **번짐**이 퍼져서, 색과 이야기가 지워지고 있다.

## 🧍 등장인물

| 인물 | 역할 |
|---|---|
| 주인공 | 이름 없음. 작가가 **마지막으로 그리다 포기한 그림**. 흐린 선 몇 개뿐이고 색도 얼굴도 없음 |
| 갈피 | 낡은 **책갈피 요정**. 안내자 역할 |
| 작가 | 현실 세계의 화가. 남들의 비웃음과 자기 실망으로 그림을 그만둠 |
| 번짐 | 최종 보스. 작가의 **자기 의심**이 잉크가 된 존재. 작가의 글씨체로 말함 |
| 각 장의 보스 | 원래 그 장의 주인공·조연이었지만 번짐에 먹혀 폭주한 캐릭터. 쓰러뜨리면 원래 모습으로 돌아옴 |

---

## 📄 프롤로그 — 표지

1. 어둠 속, 연필이 종이를 긁다가 **뚝 멈추는 소리**
2. 하얀 백지 위에서 눈을 뜸. 몸은 흐린 선 몇 개뿐이고 색이 없음
3. 멀리 책 표지가 보임. 제목은 **"Unfin"** 뒤가 검게 번져 있음
4. 갈피가 다가와 말함: *"이 책이 끝나지 않으면, 여기 있는 건 전부 지워져."*

> ✏️ *"나는… 누가 그리다 만 거지?"*

---

## 🌲 1장 — 연필 숲 · 표지 글자 i

**분위기**: 흑백. 곳곳에 지우개로 문지른 자국과 그리다 만 나무들.

| 흐름 | 내용 |
|---|---|
| 발견 | 숲 곳곳이 **지워진 흔적**투성이. 누군가 일부러 지우고 다님 |
| 역경 | 흑연 광산의 **광산 감독 지우개**. *"미완성은 지워야 깨끗해."* 주인공도 지우려 듦 |
| 해결 | 감독을 쓰러뜨리고 **연필 깎기** 획득. 무뎌진 선을 깎아 엉킨 덩굴을 자를 수 있게 됨 |
| 보스 | **엉킨 낙서 덩어리**. 누군가 화가 나서 마구 덧그은 낙서. 풀어내자 그 아래 작은 **새 그림**이 나옴 |
| 획득 | **지우개 대시**. 나를 지우려던 힘이 나를 앞으로 밀어줌 |

> ✏️ *"지우는 힘도, 앞으로 가는 데 쓸 수 있구나."*

---

## 🖍️ 2장 — 크레파스 언덕 · 표지 글자 s

**분위기**: 따뜻한 노을색이지만 너무 두껍게 덧칠돼서 끈적하고 무거움.

| 흐름 | 내용 |
|---|---|
| 발견 | 주민들이 흠을 감추려고 **자기 몸을 계속 덧칠**함. 너무 칠해서 움직이지도 못하는 주민도 있음 |
| 일기 조각 1 | 삐뚤빼뚤한 아이 글씨. *"오늘 그린 기사, 유치하대."* |
| 역경 | 녹는 발판과 밀랍 절벽. 오르다 보면 주인공의 선도 덧칠에 묻혀 흐려짐 |
| 보스 | **부러진 크레파스 기사**. 너무 세게 눌러 그려서 부러진 기사. 부러진 채로도 지키려고 싸움 |
| 해결 | 기사는 부러진 자리를 그대로 둔 채 웃음. *"부러져도 기사는 기사지."* |
| 획득 | **크레파스 벽타기** |

> ✏️ *"덧칠하지 않아도 되는 거였어."*

---

## 💧 3장 — 수채화 호수 · 표지 글자 h

**분위기**: 물감이 번진 호수. 고요하고 슬픔.

| 흐름 | 내용 |
|---|---|
| 발견 | 호수에 비친 주인공의 모습에 **얼굴이 없음**. 얼굴을 그리기 전에 멈춘 것 |
| 일기 조각 2 | 조금 자란 글씨. *"번지면 실수야. 다시 그려야 해."* 종이에 눈물 자국 |
| 역경 | 물이 선을 조금씩 녹여냄. 오래 머물수록 몸이 흐려져서 **계속 움직여야 함** |
| 보스 | **번진 물감 고래**. 젖어서 망친 그림들을 삼켜 품고 있음 |
| 해결 | 고래가 품던 그림들이 풀려나며, 번진 그림들이 오히려 수채화처럼 빛남 |
| 획득 | **물감 헤엄** |

> ✏️ *"번진 것도, 그림이었어."*

---

## 📐 4장 — 색종이 도시 · 표지 글자 e · ⚠️ 반전

**분위기**: 반듯하게 접힌 완벽한 도시. 깔끔하지만 텅 비어 있음.

| 흐름 | 내용 |
|---|---|
| 발견 | **접힌 종이 왕**이 흠 있는 것들을 전부 주름 속에 접어 숨겨서 도시가 완벽해 보이는 것 |
| 보스 | 왕을 쓰러뜨리자 주름이 펴지며 숨겨진 것들이 쏟아짐 |
| 반전 | 그중 한 장, **X 표시가 쳐진 주인공의 그림**. 옆에 작가 글씨: *"이것도 별로네."* |
| 진실 | 주인공은 작가가 그림을 그만두던 날 **마지막으로 그리다 포기한 그림**. 그래서 이름도, 얼굴도, 색도 없었음 |
| 절망 | 주저앉음. 갈피의 목소리도 들리지 않음 |
| 회복 | 지금까지 구한 것들이 찾아옴 (1장의 새, 2장의 기사, 3장의 그림들). *"우리도 다 미완성이었어. 그래도 여기 있잖아."* |
| 획득 | **종이접기 활공**. X 쳐진 그 종이를 접어 날개를 만듦 |

> ✏️ *"버려진 종이로도, 날 수 있어."*

---

## 🖋️ 5장 — 잉크 심연 · 표지 글자 d

**분위기**: 지나온 4지역이 잉크에 잠겨 뒤섞인 곳. 잉크가 계속 차오름.

| 흐름 | 내용 |
|---|---|
| 발견 | **번짐**의 정체는 작가의 **자기 의심**이 잉크가 된 것 |
| 역경 | 번짐이 작가의 글씨체로 말을 걸어옴. *"어차피 아무도 안 봐." "넌 실패작이야."* |
| 1페이즈 | 잉크 괴물. 지금까지 얻은 능력을 전부 써서 싸움 |
| 2페이즈 | 번짐이 **주인공과 똑같은 모습**이 됨. 자기 의심과의 싸움 |
| 3페이즈 | 공격이 통하지 않음. 모은 색으로 **번짐 위에 덧칠**해야 함 |
| 마지막 페이지 | 책의 마지막 장은 처음부터 **백지** (작가가 결말을 정하지 못함). 주인공이 직접 연필을 쥐고 마지막 장면을 그림 |

---

## 🌈 엔딩

| 엔딩 | 조건 | 내용 | 표지 |
|---|---|---|---|
| 🔒 노멀 | 5장 보스 처치 | 번짐을 **봉인**. 잉크가 사라지자 세상의 윤곽선도 사라져 모든 그림이 흐릿해짐. 마지막 글자 d는 잉크로만 쓸 수 있어서 쓰지 못함 | Unfinishe |
| ✨ 진 | 지역마다 숨은 **그리다 만 그림 친구** 1명씩, 총 5명을 완성 ([14 문서](14_숨은_그림친구.md): 강아지·해님·물고기·종이학·작가의 자화상) | 번짐을 없애지 않고 **받아들임**. 잉크가 세상의 윤곽선이 되어 모든 그림이 또렷해짐. 그 잉크로 d를 씀 | Unfinished |

### ✨ 진 엔딩 마지막 장면
1. 현실. 먼지 쌓인 스케치북이 저절로 펼쳐짐
2. 어른이 된 작가가 완성된 페이지들을 한 장씩 넘겨봄
3. 표지의 "Unfinished"를 한참 보다가, 새 스케치북을 꺼냄
4. 첫 장에 연필로 **누군가를 그리기 시작함**. 그림 아래 이름 칸은 **비워 둠**

> ✏️ *"끝나지 않았다는 건, 아직 그릴 수 있다는 뜻이야."*

## 🎯 핵심 메시지
**"자기 의심(잉크)은 없애야 할 적이 아니라, 그림을 완성하는 윤곽선이다."**

## 📝 연출 규칙

| 규칙 | 내용 | 상태 |
|---|---|---|
| 일기 조각 | 장마다 **1~2개만**. 많으면 설명이 되고, 적어야 상상하게 됨 | ✅ |
| 진실 전달 | 텍스트 설명보다 **지워진 낙서 흔적**으로 암시 | ✅ |
| 장 마무리 | 보스 처치 → 독백 한 줄 → 표지 글자 회복 → **걸어서 다음 장으로** (책장 넘김 없음, 다음 장 입구에서 장 제목이 잠깐 떠오름) | ✅ |
| 4장 반전 복선 | 1~3장에 "얼굴 없는 반영", "색이 안 칠해지는 몸", "X자 모양 흉터 같은 선"을 미리 깔기 | 💡 |
