# 05. 플레이어 · 조작

> 상태: 🧪 그레이박스 프로토타입 수치 (Unity로 옮길 때 기준값)
> 단위: px (1타일 = 16px), 초

## ⌨️ 조작 키

| 동작 | 키 | 비고 |
|---|---|---|
| 이동 | ← → 또는 A D | |
| 점프 | Space (↑, W, Z) | 짧게 누르면 낮게 |
| 벽 점프 | 벽에 붙은 상태에서 점프 | 처음부터 사용 가능 |
| 공격 (지우개) | X 또는 J | |
| 지우개 대시 | Shift (K) | 1지역 보스 처치 후 |

> 패링 키는 2장 문서에서 정리 예정.

## 🧍 기본 능력치

| 항목 | 값 |
|---|---|
| 크기 | 12 × 22px (0.75 × 1.4 타일) |
| 체력 | 5 (체력 조각 1개당 +1, 1지역 최대 8) |
| 피격 후 무적 | 1.0초 |
| 피격 넉백 | 가로 190 / 위 230, 0.2초 조작 잠김 |
| 사망 | 마지막 세이브에서 체력 가득 차서 부활, 엘리트·보스는 체력 리셋 |

## 🏃 이동

| 항목 | 값 | 타일 환산 |
|---|---|---|
| 땅 이동 속도 | 125 px/s | 7.8 타일/초 |
| 공중 이동 속도 | 150 px/s | 9.4 타일/초 |
| 땅 가속 | 빠름 (반응 계수 18) | |
| 공중 가속 | 조금 느림 (반응 계수 10) | |

## 🦘 점프 ✅ (앞으로 낮게 뛰는 느낌)

| 항목 | 값 |
|---|---|
| 중력 | 1350 px/s² |
| 점프 초속 | 425 px/s (이전 445에서 낮춤) |
| 점프 순간 앞쪽 밀어주기 | 방향키를 누르고 있으면 가로 155 px/s |
| 최대 높이 | **약 4.2타일** |
| 최대 거리 | **약 5.9타일** |
| 짧은 점프 | 상승 중 버튼을 떼면 상승 속도 × 0.45 |
| 낙하 최고 속도 | 430 px/s |
| 코요테 타임 | 0.09초 (발판에서 떨어진 직후에도 점프 가능) |
| 점프 입력 버퍼 | 0.12초 (착지 직전 입력도 인정) |

## 🧱 벽 점프

| 항목 | 값 |
|---|---|
| 벽 미끄러짐 | 벽 쪽 방향키를 누르면 낙하 속도 최대 60 |
| 벽 점프 | 위 420, 벽 반대쪽 175 |
| 조작 잠김 | 0.17초 (벽에서 튕겨나가는 느낌) |

> 💡 2지역의 크레파스 벽타기와 겹치지 않게, 벽타기는 "매끈한 밀랍 벽까지 오르는 상위 능력"으로 차별화하는 안이 나와 있음.

## ✏️ 지우개 공격

| 항목 | 값 |
|---|---|
| 판정 시간 | 0.14초 |
| 재사용 | 0.3초 |
| 판정 크기 | 바라보는 쪽 22 × 20px |
| 피해 | 1 |
| 적 넉백 | 130 px/s, 0.15초 |
| 탄 지우기 | **작은 탄(연필밥)만** 지울 수 있음. 보스 낙서 탄·잉크는 못 지움 |
| 연필 깎기 획득 후 | 같은 공격으로 **흑연 덩굴**을 자름 (세로 한 줄 통째로) |
