# 05. 플레이어 · 조작

> 상태: 🧪 그레이박스 프로토타입 수치 (Unity로 옮길 때 기준값)
> 단위: px (1타일 = 16px), 초

## ⌨️ 조작 키

| 동작 | 키 | 비고 |
|---|---|---|
| 이동 | **A D** | W·S는 위·아래 방향 입력 (점프·내려가기 조합용) |
| 점프 | **Space** | 앞으로 낮고 길게. 짧게 누르면 낮게 |
| 위로 점프 | **W + Space** | 앞으로 밀어주는 힘 없이 제자리에서 위로 (높이는 같음) |
| 책갈피 리본 | 리본 앞 **W 길게 (0.3초)** | 정해진 짝으로 이동 ([15 문서](15_책갈피_이동.md)) |
| 그리기 | **W 길게 (1.2초)** | 숨은 그림 친구 옆에서 빠진 부분을 채움 ([14 문서](14_숨은_그림친구.md)) |
| 내려가기 | **S + Space** | 통과 발판 위에서 아래로 내려감. 단단한 바닥에서는 아무 일 없음 |
| 벽 점프 | 공중에서 벽에 붙은 상태로 Space | **1장 2번 방 서쪽 끝 ✋ 또렷해진 손**을 주우면 해금 (밀랍 벽 제외). 해금 전엔 벽에 붙어도 미끄러지지 않고 튕기지도 않음 |
| 공격 (지우개) | **J** | 땅에서 연타하면 콤보 (상세는 [11 문서](11_전투_성장.md)) |
| 대시 베기 | 대시 중 J | 지우개 대시 획득 후 |
| 튕겨치기 | 패링 성공 직후 J | 2장 |
| 덧칠 일격 | J 1초 꾹 눌렀다 떼기 | 5장 (제안) |
| 패링 | **K** | 2장 (상세는 2장 문서) |
| 아이템 사용 | **L** | 지금 고른 아이템 사용 ([12 문서](12_아이템.md)) |
| 아이템 바꾸기 | **Q** | 가진 아이템을 차례로 바꿈 (임시 배치) |
| 지우개 대시 | **Shift** | 1지역 보스 처치 후 |

### 통과 발판
- 회색 발판과 무너지는 발판은 **아래에서 뛰어 통과**하고 **위에서만 밟히는** 발판
- 옆에서 부딪히지 않고, 벽 점프용 벽으로도 쓰이지 않음
- 적도 통과 발판 위를 걸어 다님, 적 탄은 발판을 통과함

## 🧱 벽 점프

| 항목 | 값 |
|---|---|
| 벽 미끄러짐 | 벽 쪽 방향키를 누르면 낙하 속도 최대 60 |
| 벽 점프 | 위 420, 벽 반대쪽 175 |
| 조작 잠김 | 0.17초 (벽에서 튕겨나가는 느낌) |

> ✅ 벽 점프는 **1장 시작 직후 해금**(✋ 또렷해진 손) → 바로 위 바람 굴뚝에서 써 봄. 벽 점프는 **일반 벽**, 2장 크레파스 벽타기는 **매끈한 밀랍 벽**까지 오르는 상위 능력. 1장에 **벽 점프 전용 구간 2곳**(바람 굴뚝 · 풀 그림자 굴 굴뚝)을 둬서 먼저 확실히 익히게 함 ([04 문서](04_1지역_연필숲_맵.md))
