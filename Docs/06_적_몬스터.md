## 👀 존재감 연출 ✅ (인게임 텍스트 없이)

| 요소 | 내용 |
|---|---|
| 크기 | 일반 적 기본 크기의 **1.3~1.35배** (충돌 범위도 같이) |
| 대기 동작 | 땅에 있는 적은 숨쉬듯 살짝 늘었다 줄었다 함 |
| 그림자 | 땅에 있는 적 발밑 타원 그림자 |
| 발견 반응 | 170px 안에서 처음 발견하면 **움찔 뛰어오르고**(위 150) 머리 위에 **놀람 선 3개** (0.45초) |
| 피격 | 맞으면 **찌그러짐** + 연필 가루 |
| 처치 | 색 가루 + 종이 조각이 흩어짐 |
| 두더지 | 숨어 있어도 **흙더미**가 보임 (위치는 알려주고 튀어나오는 타이밍만 숨김) |
| 거미 | 천장에서 내려오는 **실**이 보임 |
| 최적화 | 플레이어와 520px 이상 떨어진 적은 정지 (보스 제외) |

## 👥 배치 원칙 ✅

1. **새 적은 처음에 혼자 소개** → 다음 방부터 기존 적과 섞기
2. 방마다 **역할이 다른 2~3마리 조합** (예: 앞에서 막는 근거리 + 뒤에서 쏘는 원거리)
3. **세이브 주변 2타일은 비워 둠**. 10·21번은 적 없는 쉬는 방
4. 앞 구역 적을 뒤 구역에도 섞어서 **구역마다 5~6종**이 보이게
5. 강화판은 **지역 후반에 소수만**

| 5 갈림길 굴 | 벌레 + 종이공 + 포탑 | 허브 첫 혼합 전투 |
| 6 갈림굴 다락 | 포탑 2 | 엇갈리는 탄 사이로 이동 |
| 8 흑연 갱도 | 벌레·두더지·나방·포탑·종이공 | 잉크 구덩이 옆 혼전 |
| 13 옹이 방 | 벌레 2 + 거미 | 위아래 동시 압박 |
| 15 가지 속 통로 | 종이공·벌레·두더지·포탑 | 나무 구역 마무리 시험 |
