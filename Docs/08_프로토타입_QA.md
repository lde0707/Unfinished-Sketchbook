# 08. 프로토타입 · QA

## 🧪 그레이박스 프로토타입

| 항목 | 내용 |
|---|---|
| 형태 | 브라우저에서 바로 플레이하는 HTML 페이지 (Claude 아티팩트, 비공개) |
| 포함 내용 | 레퍼런스 7개 분석, 5지역 월드맵, 지역 상세, **1지역 연필 숲 플레이 맵** |
| 현재 버전 | 1지역 v21 · 2지역 v1 |
| 파일 | `Prototype/unfin_prototype.html` (1지역) · `Prototype/unfin_region2.html` (2지역) |
| 목적 | 동선·점프 거리·능력 게이트·전투 밀도를 실제 플레이어 크기로 검증 |

## 🛠️ QA 도구

| 도구 | 기능 |
|---|---|
| 처음부터 | 맵·적·아이템 전체 리셋 |
| 연필 깎기 해금 | 엘리트를 잡지 않고 바로 연필 깎기 |
| 대시 해금 | 보스를 잡지 않고 바로 지우개 대시 |
| 비행 모드 (F키) | 중력 없이 상하좌우 비행, **벽 통과**, 무적. Shift로 2배 속도. 벽 속에서는 꺼지지 않음 |
| 무적 | 적·탄 피해 무시 (잉크는 복귀만) |
| 충돌 박스 | 플레이어·적·공격 판정 박스 표시 |
| 세이브로 이동 | 세이브 석상 5곳으로 순간이동 |
| 페이지 넘김 미리보기 | 출구까지 가지 않고 전환 연출 확인 |
| 아이템 3종 지급 | 물감 탄·회복 물감·종이 방패 바로 받기 ([12 문서](12_아이템.md)) |
| 3타 접기 베기 / 덧칠 일격 | 4장·5장 콤보를 미리 켜서 손맛 테스트 ([11 문서](11_전투_성장.md)) |
| 벽타기 / 물감 헤엄 / 활공 | 다른 지역 능력을 흉내 내서 1지역 재방문 보상 테스트 ([10 문서](10_능력_성장.md)) |
| 타이머 | 화면 오른쪽 위, 출구 도달 시 클리어 시간 고정 |
| 미니맵 | 280 × 140 전체, 구역 색, 방 번호, 적 위치(유형별 색), 수집품, 카메라 범위 |

> 프로토타입에는 2장용 패링 테스트 기능도 들어가 있지만, 이 문서 범위에서는 제외.

## ✅ 자동 검증 항목 (맵을 바꿀 때마다 실행)

| 검사 | 내용 |
|---|---|
| 스폰 위치 | 몬스터·아이템이 벽 속에 박히거나 공중에 뜨지 않음 |
| 능력별 도달 범위 | 능력 없음 / 연필 깎기 / 연필 깎기 + 대시 각각 갈 수 있는 곳이 의도와 같은지 |
| 계단 발판 | 발판 위 2칸이 비어 있는지 (머리 박힘 방지) |
| 바닥 파임 | 방 바닥에 폭 1~2타일 구멍이 없는지 |

## ⏱️ 플레이타임 목표

| 구간 | 내용 | 인게임 목표 |
|---|---|---|
| 탐험·이동 | 방 약 28개, 방당 평균 30초 | 14분 |
| 일반 전투 | 방마다 2~3마리 조합 | 6분 |
| 기믹 방 | 흑연 덩굴, 무너지는 발판, 잉크 구간 | 4분 |
| 엘리트 2 + 보스 | 재도전 1~2회 포함 | 4분 |
| 되돌아오기·비밀 | 중간 능력 후 재방문 | 2분 |
| **합계** | | **30분** |

- 첫 프로토타입(방 9개) 클리어 시간: **약 4분** → 확장
- 그레이박스는 아트·사운드·연출이 없어 빨리 지나가므로 **12~15분**이 나오면 인게임 30분 근처로 판단
