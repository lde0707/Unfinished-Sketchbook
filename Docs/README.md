## 📌 범위

- 이 문서는 **1지역 연필 숲**까지 구체화된 내용을 중심으로 정리했어. 2지역 크레파스 언덕은 맵 + 프로토타입 v1 단계.
- **패링 시스템은 2장 개발 때 따로 정리할 예정이라 이 문서에서 제외**했어. (프로토타입에는 테스트용으로 들어가 있지만 확정 사양이 아님)
- 좌표와 크기는 모두 **타일 단위** (1타일 = 16px = Unity 1유닛).
