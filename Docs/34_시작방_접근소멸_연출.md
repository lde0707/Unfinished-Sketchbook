# 프롤로그 — 지워지는 첫 장

2026-11-04 · 별도 플레이 맵과 1지역 연결.

## 플레이 흐름

타이틀 → 새 이야기 → **지워지는 첫 장** → 오른쪽 페이지 통로 → **1지역 원래 시작점(244, 131)**.

- 프롤로그는 `StilldrawnPrologue.unity`라는 독립 씬이다. 기존 1·2지역 맵 구조와 시작 좌표를 바꾸지 않는다.
- 56 × 22칸의 짧은 종이 동굴이다. 안전한 평지, 기본 점프로 넘는 1칸 턱, 선택적으로 밟는 작은 선반을 둔다.
- 플레이어는 직접 이동한다. 기존 플레이어 원화·프레임·비율·이동·점프 애니메이션을 그대로 사용한다.
- 전투 적이나 아이템 획득은 없으며, 체력·미니맵 HUD를 잠시 숨긴다. ESC 일시정지와 설정은 계속 사용할 수 있다.

## 그림이 사라지는 경험

| 대상 | 발 위치 | 연출 |
|---|---|---|
| 첫 종이 몬스터 | (12, -16) | 32프레임 · 1.6초 |
| 종이 나무 | (25, -16) | 32프레임 · 2.4초 |
| 마지막 종이 몬스터 | (37, -16) | 32프레임 · 1.6초 |

처음부터 완성된 모습으로 존재한다. 같은 높이에서 접근하면 소멸하며, 멀어져도 끝까지 진행한다. 나무 반경 1.367유닛, 몬스터 1.523유닛. 다른 층이나 벽 너머에서는 발동하지 않는다. 잔해도 마지막 구간에 사라진다. 재접근으로 반복하거나 피해·보상을 주지 않는다.

## 이야기와 연결

이동 중 짧은 문장을 보여 준다.

1. 펜이 멈춘 뒤, 그림들은 조금씩 지워지고 있었다.
2. 방금까지… 여기 있었는데.
3. 이 책이 끝나지 않으면, 여기 있는 건 전부 지워져.
4. 지워지기 전에, 다음 장으로.

그림 세 개의 소멸이 끝난 뒤 오른쪽 통로(x ≥ 49)에 발을 디디면 0.7초 동안 암전한다. 다음 씬을 비동기로 불러와 기존 1지역 시작점에서 화면을 밝힌다. 별도 확인 버튼은 없다. 프롤로그 전용 통로는 일반 포탈의 이동망에 등록하지 않는다.

## 저장과 호환

- `StilldrawnSave.inPrologue`: 현재 프롤로그에 있는 저장인지 구분한다.
- 프롤로그 저장은 현재 위치와 `proximityStoryGoneMask`를 기록한다. 중간에 나갔다 이어도 이미 사라진 그림을 반복하지 않는다.
- 프롤로그를 끝내면 기존 1지역 저장 형식으로 자동 전환한다. 기존 메인 맵 저장은 프롤로그를 강제 재생하지 않는다.
- 새 이야기는 프롤로그부터 초기화한다. 타이틀과 이어하기에는 ‘프롤로그 · 지워지는 첫 장’을 표시한다.

## 구현과 검증

- `PrologueMapBuilder`: 씬, 지형, 기존 아트 재사용, 기본 이동 경로 검증.
- `PrologueFlow`: 위치별 짧은 문장, 출구 조건, 암전과 지역 연결.
- `ProximityStory`: 승인된 32프레임 소멸 원화 재생.
- `WorldSession` / `StilldrawnTitle`: 저장 위치에 따른 씬 선택.
- Unity 메뉴: `Unfin > Build Playable Prologue`.
- 웹 전체 흐름 검사: `node Tools/check_prologue_web.cjs` (새 이야기, 이동·점프, 프롤로그 중간 이어하기, 1지역 도착, 일반 이어하기).
- 검증 결과: `Book/Validation/prologue.json`, `Book/Validation/prologue/`.
