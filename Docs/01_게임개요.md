# 01. 게임 개요

> 제작 기준: [21 고해상도 타일맵 규격](21_고해상도_타일맵_규격.md). 고해상도 비도트 그래픽, 지형 256×256px/칸, PPU 256.

## 🎮 기본 정보

| 항목 | 내용 | 상태 |
|---|---|---|
| 제목 | **Unfin** (저장소명: Unfinished-Sketchbook, 구 가제: 미완의 스케치북) | ✅ |
| 장르 | 2D 메트로배니아 (탐험 + 능력 게이트 + 보스) | ✅ |
| 세계관 | 작가가 그리다 버려둔 **스케치북 속 도화지 세상** | ✅ |
| 지역 수 | 거대한 맵 1개 안에 **5개 지역** | ✅ |
| 지역당 플레이타임 | 인게임 기준 **약 30분** (그레이박스 기준 12~15분 목표) | ✅ |
| 엔진 | **Unity 2D (URP)** 권장 | 💡 |

## 💡 핵심 콘셉트

- 지역 = 책의 **장(章)**, 보스 = 장의 수호자, 능력 = **그림 도구**
- 보스를 쓰러뜨릴 때마다 책이 한 장씩 완성되고, 흑백이던 세상에 **색이 돌아옴**
- 지역 사이는 **책 넘김 없이 걸어서 그대로 이어짐**. 경계에서 종이 색과 선 색이 천천히 다음 지역 색으로 바뀜

## 🔑 제목 장치 ✅

- 표지에는 **"Unfin"** 까지만 적혀 있고 뒷부분은 잉크에 번져 있음
- 장을 하나 완성할 때마다 표지에 글자가 하나씩 돌아옴

| 완성한 장 | 표지 |
|---|---|
| 시작 | Unfin |
| 1장 연필 숲 | Unfin**i** |
| 2장 크레파스 언덕 | Unfini**s** |
| 3장 수채화 호수 | Unfinis**h** |
| 4장 색종이 도시 | Unfinish**e** |
| 5장 잉크 심연 (진 엔딩) | Unfinishe**d** |

→ 끝까지 완성했는데 제목은 "Unfinished(미완성)". 이 아이러니가 엔딩의 메시지가 됨.

## 👤 주인공 시점 규칙 ✅

| 규칙 | 내용 |
|---|---|
| 이름 | **끝까지 나오지 않음**. 다른 캐릭터들은 "너"라고만 부름 |
| 말 | 주인공은 소리 내 말하지 않음 |
| 독백 | 화면 여백에 **연필 글씨**로 짧게 나타났다 지워짐 |
| 정보 전달 | 설명 대사 대신, 직접 보고 줍는 것(일기 조각, 지워진 흔적)으로 진실을 알아감 |
| 플레이어와의 관계 | 이름이 없기 때문에 **플레이어 = 그 그림**이라는 느낌을 줌 |

| 밝기 | 방별 낮은~중간 명도, 절제된 국소광·안개. 주인공·적·탄·발판은 배경과 선명히 분리 | ✅ |
| 깊이감 | 3D 대신 **패럴랙스 배경 여러 겹**으로 표현 | 💡 |

## 🛠️ 엔진 선택 이유 (Unity 2D 권장)

| 항목 | 이유 |
|---|---|
| 맵 옮기기 | 프로토타입 맵을 Tilemap에 1타일 = 1유닛으로 그대로 옮길 수 있음 |
| 그림체 | 깔끔한 그래픽 스프라이트를 그대로 사용 |
| 조작감 | Rigidbody2D + 타일맵 충돌로 점프·벽 점프를 다루기 쉬움 |
| 지형 파괴 | 낙서 벽·흑연 덩굴은 타일 하나 지우면 끝 |
| 추천 기능 | 고해상도 Tilemap + Rule Tile(256px/칸, PPU 256), 여러 타일셋·시각 레이어, Sprite Shape(필요한 곡선만 선택), 2D Light(URP), Cinemachine, 패럴랙스 |
